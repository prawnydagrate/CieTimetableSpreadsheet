# Usage

`make_csv.py` generates CSV files from CIE examination timetables.

```bash
usage: make_csv.py [-h] file output

positional arguments:
  file        a valid path to the PDF of the timetable, or a valid URL to it
  output      the output file path at which to save the processed CSV file

options:
  -h, --help  show this help message and exit
```
